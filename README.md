# Shahnameh - Seven Trials of Rostam

A Git practice project based on the story of Rostam's Seven Trials from Shahnameh.

## Chapters

- Chapter 1: The Beginning of Rostam's Journey
- Chapter 2: The Lion Trial
- Chapter 3: The Desert Path
- Chapter 5: Battle with the Dragon
- Chapter 6: Hidden Memories
- Chapter 7: Forgotten Message
- Chapter 8: The White Demon Battle

## Git Commands Practiced

- Branching
- Merge and Conflict Resolution
- Rebase
- Stash
- Restore
- Reset
- Revert
- Reflog
- Clean
- GitHub SSH Push
